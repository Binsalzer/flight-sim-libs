# Learjet 35A flight simulator - libraries

Pre-built JavaScript libraries loaded by the game through jsDelivr
(`https://cdn.jsdelivr.net/gh/Binsalzer/flight-sim-libs@main/libs/sim-libs-<hash>.js`). No game code here.

`libs/sim-libs-<hash>.js` bundles these open-source packages, unchanged, under their own licences:
- three.js 0.186.1 - MIT (c) three.js authors
- 3d-tiles-renderer 0.5.3 - Apache-2.0 (c) NASA-AMMOS / Garrett Johnson
- postprocessing 6.39.6 - Zlib (c) Raoul van Rueschen
- @takram/three-geospatial 0.9.1, three-atmosphere 0.19.1, three-clouds 0.7.6 - MIT (c) takram

`assets/stbn.bin` - spatio-temporal blue noise texture from @takram/three-geospatial (MIT).
